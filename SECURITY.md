# Security Policy

## Supported versions

None. This project stopped maintenance on October 20, 2026. No version receives
security fixes, and reports are not actively monitored. Existing releases are
retained for reference and recovery, without ongoing support. See the
[recovery instructions](https://github.com/cixiangtao/codex-vscode-project-patch#remove-the-patch-and-return-to-the-official-extension)
to return to the official extension.

## Reporting a vulnerability

Use GitHub private vulnerability reporting from the repository's **Security**
tab when it is available. Do not open a public issue for a vulnerability that
could enable arbitrary file modification, unsafe restore behavior, path escape,
or execution of untrusted extension content.

The archived issue tracker is read-only. Never include an official OpenAI
extension bundle, credentials, private paths, or personal data in a report.

This project is an unofficial local patching tool. Reports about the official
OpenAI extension itself should be sent to OpenAI through its own security
reporting process.
